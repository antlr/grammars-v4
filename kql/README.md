# KQL Grammar

An ANTLR4 grammar for the [Keyword Query Language (KQL)](https://learn.microsoft.com/en-us/sharepoint/dev/general-development/keyword-query-language-kql-syntax-reference),
the query language used by SharePoint and Microsoft Search.

The grammar's BNF is derived from the [MS-KQL specification](https://download.microsoft.com/download/C/6/C/C6C3C6F1-E84A-44EF-82A9-49BD3AAD8F58/SharePoint/%5BMS-KQL%5D.pdf).
