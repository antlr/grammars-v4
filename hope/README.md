# Hope Grammar

An ANTLR4 grammar for [Hope](https://en.wikipedia.org/wiki/Hope_(programming_language)), an
experimental, strongly-typed, purely applicative (no assignment) functional programming
language developed at the University of Edinburgh in the late 1970s. Hope introduced
user-defined algebraic data types and pattern-matching function definitions, and influenced
later languages such as Miranda and Haskell.

See the original language report: R.M. Burstall, D.B. MacQueen, D.T. Sannella,
["HOPE: An Experimental Applicative Language"](https://doi.org/10.1145/800055.802038), 1980
(included in this directory as `hope.pdf`).
