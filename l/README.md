# L Grammar

An ANTLR4 grammar for [L](http://home.cc.gatech.edu/tony/uploads/61/Lpaper.htm), a small
homoiconic language built from a handful of composition forms: adjacent application
(`f x`), dot application (`a.b`), tuples (`1,2,3`), statement series (`a;b;c`), and
bracketed blocks/records (`[...]`, `{...}`).
